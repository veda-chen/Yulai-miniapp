# 羽来隐私与微信审核清单

公众平台填写内容见《微信公众平台隐私指引填写稿》。

## 当前代码实际处理的数据

| 数据 | 是否必需 | 用途 | 当前控制 |
| --- | --- | --- | --- |
| 微信 OpenID | 系统必需 | 识别当前微信用户 | 仅云函数读取，使用 HMAC 后的值入库 |
| 昵称 | 参与组局必需 | 组织者和参与者展示 | 1–24 字符，可修改 |
| 头像 | 可选 | 个人主页展示 | 用户主动选择，可更换或移除；旧文件和注销账号时删除 |
| 学校 | 可选 | 个人资料展示 | 可不填、可修改、可清空 |
| 自评水平 | 可选 | 球局匹配和分组参考 | 可选“不清楚”，可修改 |
| 球局内容 | 创建时必需或可选 | 发布活动 | 服务端校验长度和权限 |
| 联系方式 | 可选 | 线下联系 | 默认仅组织者和正式参与者可见 |
| 报名、到场、分组和比分 | 使用功能时产生 | 履行组局与现场功能 | 对象级权限、审计和比分修订记录 |
| 举报内容 | 用户主动提交 | 平台治理 | 仅举报人与管理员业务流程使用 |
| 订阅授权结果与加密接收标识 | 用户主动设置提醒时产生 | 记录模板授权并准备微信提醒 | 独立密钥 AES-GCM 加密；注销时立即删除 |

## 当前未调用的敏感能力

代码扫描未发现定位、选择地址、手机号或剪贴板授权 API。编辑资料页通过微信头像选择能力让用户主动选择头像，不在后台调用相册或相机；头像上传到用户专属云存储路径，服务端只接受当前用户路径。消息页已接入 `wx.requestSubscribeMessage`，仅在用户点击且正式模板 ID 已配置时调用；授权结果会写入受限集合，拒绝授权不影响报名。后续新增其他敏感能力时，必须先更新本清单、公众平台隐私保护指引和用户界面。
