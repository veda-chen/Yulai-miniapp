# 羽来隐私与微信审核清单

## 当前代码实际处理的数据

| 数据 | 是否必需 | 用途 | 当前控制 |
| --- | --- | --- | --- |
| 微信 OpenID | 系统必需 | 识别当前微信用户 | 仅云函数读取，使用 HMAC 后的值入库 |
| 昵称 | 参与组局必需 | 组织者和参与者展示 | 1–24 字符，可修改 |
| 学校 | 可选 | 个人资料展示 | 可不填、可修改、可清空 |
| 自评水平 | 可选 | 球局匹配和分组参考 | 可选“不清楚”，可修改 |
| 球局内容 | 创建时必需或可选 | 发布活动 | 服务端校验长度和权限 |
| 联系方式 | 可选 | 线下联系 | 默认仅组织者和正式参与者可见 |
| 报名、到场、分组和比分 | 使用功能时产生 | 履行组局与现场功能 | 对象级权限、审计和比分修订记录 |
| 举报内容 | 用户主动提交 | 平台治理 | 仅举报人与管理员业务流程使用 |

数据库包含 `avatarFileId` 预留字段，但当前页面没有头像选择或上传功能，因此当前版本不收集头像。

## 当前未调用的敏感能力

代码扫描未发现定位、选择地址、相册、相机、手机号、剪贴板或订阅消息授权 API。后续一旦接入这些能力，必须先更新本清单、公众平台隐私保护指引和用户界面。
