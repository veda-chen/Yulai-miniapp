## 权限和第三方处理

当前版本不申请定位、通讯录、手机号、麦克风或剪贴板权限，也未接入广告、统计、地图、支付或其他第三方 SDK。编辑个人资料时可以由用户主动调用微信头像选择能力并上传头像；未选择头像不影响任何功能。管理员维护场馆资料时可以主动从相册或相机选择场馆封面和平面图，该能力不向普通用户开放。

业务数据通过微信云开发 CloudBase 的云函数、云数据库和云存储能力处理。填写平台声明时，应按后台对微信及腾讯云服务的当前归类选择，不能把尚未接入的能力提前勾选。

## 用户权利入口

- 修改头像、昵称、学校和自评水平：“我的 → 编辑个人资料”
- 移除头像：“我的 → 编辑个人资料 → 移除头像”
- 清空学校：编辑个人资料时选择不填写
- 查看隐私说明和联系运营者：“我的 → 隐私与数据”
- 注销账号：“我的 → 注销账号”
- 查询、更正、删除其他个人信息或投诉：发送邮件至 2724309224@qq.com

## 后台配置步骤

1. 登录对应 AppID 的微信公众平台，进入小程序设置中的隐私保护指引。
2. 填写运营主体、联系邮箱和主要用途。
3. 逐项选择本稿中实际处理的信息，只填写当前版本已经使用的目的和场景。
4. 核对当前未使用的权限与 SDK，确保没有多报或漏报。
5. 保存后生成体验版，分别验证首次进入、拒绝、再次进入、编辑资料和注销账号。
6. 将后台最终文本与本稿逐句比对，把截图、核验日期和审核人记录到 release/m5-gates.json。
7. 只有体验版行为、后台声明和代码三者一致时，才能把隐私门槛改为 PASSED。
