# 轮转组局与界面修复验收记录

日期：2026-09-28

## 本轮完成

- 首页消息入口改用固定比例矢量图标，保留真实未读红点。
- “我的”移除重复的“找球局”入口。
- 个人资料中的学校和水平选择内容改为水平、垂直居中。
- 费用均摊的“增加费用”和“计算均摊”按钮统一高度、内边距和文字基线。
- 将快速分组、轮转排场、随机抽签合并为“轮转组局”，工具页和首页快捷工具只展示一个入口。
- 轮转组局支持公平轮转、快速随机和八人转；支持随机排序名单、临时休息、单双打、多场地、候场、撤销、可选比分及现场排名。
- 八人转固定 8 人双打、2 片场，一次生成 8、16 至 80 轮；前 7 轮保证 28 组两人搭档不重复，后续轮次均匀进入下一轮换周期。
- 旧的快速分组和随机抽签页面入口自动跳转到轮转组局；V4 个性化设置仍保留兼容字段，界面会自动去重。
