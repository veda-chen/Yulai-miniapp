# 羽来 M3 运营与通知模块

## 完成范围

- 关键变更：开始和结束时间、报名截止、场馆、场号及容量发生变化时，生成带前后值的版本记录，正式成员状态重置为待确认。
- 变更确认：正式成员可确认最新变更，组织者可查看已确认与待确认人数。
- 活动生命周期：组织者可以开始、取消和结束球局；取消必须填写原因，结束时生成已参加或未到场记录。
- 到场管理：组织者可将正式成员标记为待确认、已到场、未到场或已离场，不依赖GPS。
- 截止后递补：报名截止后不自动递补，由组织者在有空位时从候补名单手动补入。
- 通知中心：报名、候补、递补、关键变更、截止后退出、取消和结束均生成幂等站内通知；用户拒绝外部通知不影响主流程。
- 举报流程：登录用户可举报球局、场馆或用户；相同未处理举报不重复创建。
- 场馆维护：管理员可录入核验资料、设施、封面和平面图；发布为已核验前必须具备地址、入口、开放说明、核验日期和来源。
- 运营管理：管理员可查看基础指标，按待处理、已处理和已驳回筛选举报，查看审计记录，记录处置结果、下架球局及限制账号；对象处置可同步结案对应举报，所有高影响操作进入审计日志。
- 隐私控制：新增集合均为 `ADMINONLY`；受限联系方式继续只对组织者和正式参与者返回。

## 数据与权限

新增 `activityChanges`、`notificationJobs` 和 `reports` 三个集合及所需索引。用户角色由服务端用户记录提供，客户端无法修改。管理员接口再次在服务端检查 `ADMIN` 角色，页面是否显示不作为权限依据。

微信一次性订阅消息已接入公众平台正式模板：球局变更和取消共用“预约申请处理通知”，候补递补使用“信息提交成功通知”。M3已完成通知任务、幂等键、站内展示、用户主动授权、相同模板去重、加密接收映射和每分钟定时发送；订阅授权不会阻断报名。
