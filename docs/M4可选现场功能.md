# 羽来 M4 可选现场功能

## 完成范围

- 现场模式仅在球局开始且组织者开启组队或计分后显示，两个功能可以独立使用。
- 组队使用整轮双打：每场4人、每人同轮最多一场、每片场地同轮最多一场。系统优先安排历史上场次数较少的已到场球友，再按自评水平平衡两队。
- 分组先生成待发布建议；组织者可用已选4人调整单场，服务端再次校验到场状态及同轮冲突，确认后发布整轮。
- 未启用系统组队时，正式成员可手动选择2人创建单打对局，或选择4人创建双打对局。
- 本球局所有正式成员均可提交比分；每次写入携带版本号。过期版本会保存为冲突修订并要求客户端刷新，不会覆盖当前比分。
- 对局双方各一名球员确认相同比分后自动锁定。组织者可直接锁定争议比分，也可填写原因解锁更正。
- 默认比分校验为单局21分、领先2分、30分封顶。该规则是产品默认值。
- 只有锁定结果进入个人场次、胜负和胜率；活动结束时未锁定对局作废，活动取消时全部对局从长期统计剔除。

## 数据与权限

新增 `rounds`、`matches`、`matchPlayers` 和 `scoreRevisions`。四个集合均禁止客户端直读写，所有操作经过统一云函数完成对象级权限与功能开关校验。

## 验收

- 10个测试文件共34项测试通过；纯领域测试覆盖不重复分组、优先轮休、队伍识别和羽毛球比分规则。
- 路由、集合、页面和安全规则由 `pnpm m4:verify` 检查。
- `m4-commands.json` 创建四个集合及基础索引，`m4-index-patch.json` 补充到场筛选和队伍更新索引。
- 微信开发者工具预览编译通过；M4集合、索引与安全规则已应用到开发环境。
