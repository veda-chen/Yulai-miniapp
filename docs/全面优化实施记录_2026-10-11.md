# 羽来小程序全面优化实施记录（2026-10-11）

本记录对应当前工作区，尚未形成可发布版本。开始实施前工作区已有未提交的视觉、导航、页面和截图改动；本轮在其上继续修改，未清理或覆盖这些改动。正式版本应在确定 Git 提交后重新构建、生成 `pnpm release:snapshot` 清单，并记录微信上传版本和云函数部署记录。

## 已落地

- 视觉与交互：沿用首页照片封面及轻玻璃导航，保留四个底部入口；外观页调整为预设、当前方案、紧凑预览、基础选项、高级折叠的顺序，手工修改显示“自定义”，原配置和云同步继续沿用。统一语义字号、主要按钮最小 44px、减少动效时取消按压缩放。找局与场馆并行加载；工具首页按有效本机草稿显示继续入口；创建草稿输入 400ms 合并保存并在离开时落盘。
- 页面状态：详情、历史、消息、现场和个人页加入请求代次／生命周期保护；消息点击先进入详情，再异步更新已读；个人资料、球局数量和战绩分别加载，失败显示不可用而非 0；现场比分按对局 ID 保留未提交输入，空比分不能提交为 0。
- 服务端正确性：统一联系方式可见性；容量调整事务内复核；取消或结束球局时清理候补，同时保留已锁定比分和战绩；注销按真实活动状态检查待处理事项，并匿名化历史及组织者联系方式；报名和注销通过同一用户文档写入避免并发穿透。受限账号的业务写入被服务端拒绝，读取、退出、注销仍可使用。定时任务拒绝携带客户端 OpenID 的伪造调用。
- 数据与性能：新增认证接口 `activity.mySummary`，统计仅链接可见的球局且不受列表第一页限制；本人球局先筛有效报名并遍历全部分页；找球局时间范围下推数据库，找局和消息追加页只传新增条目；战绩以数据库计数覆盖全部有效胜负。会话在途请求合并，场馆元数据短缓存，成功维护后失效。场馆详情区分待核验与资料缺失。
- 通知与清理：通知任务事务认领、租约、指数退避；平台已接受但状态保存失败进入 `VERIFY_REQUIRED`，不自动重发。注销头像删除前在事务内落清理任务，每日维护重试失败的文件删除。
- 工程与发布：开发、体验、正式环境分别生成客户端配置；正式云函数部署前检查目标环境与发布门槛。新增数据库索引及头像清理集合定义。统一入口记录脱敏的动作、结果、耗时和请求编号；新增发布映射清单生成器和 JSON 隔离恢复计划生成器。

## 本地验证

- `pnpm check`：格式、Lint、类型、90 项测试、UI 行为校验及 M1–M5 自动候选范围均通过。
- `pnpm build`：云函数 TypeScript 产物生成成功。
- `pnpm restore:json-plan -- --backup .backups/20260910T065214Z --target-env isolated-test-env`：能生成隔离导入清单，并识别旧备份缺少新增集合。
- `pnpm release:snapshot`：生成本地清单，明确提示工作区未提交。
- `pnpm release:gate`：按预期拒绝发布，六项真实门槛仍未通过。
