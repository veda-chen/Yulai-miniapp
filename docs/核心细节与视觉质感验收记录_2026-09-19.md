# 核心细节与视觉质感验收记录

日期：2026-09-19
候选版本：0.2.3

## 本轮完成

- 首页搜索区分输入关键词与已展示关键词，限制为 50 个字符；取消的防抖任务和过期响应不会覆盖新结果。
- 搜索关键词通过编码传入完整列表；当前批次为空但仍有后续页时提供继续查看，不误报无结果。
- “我的球局”及推荐刷新失败时保留已有卡片并提供就地重试；未读查询增加页面生命周期与请求版本保护。
- 球局详情将报名、候补和组织者操作结果改为页面内持续提示；后台刷新失败可重试，且只在触发的按钮显示加载状态。
- 球局不存在、链接无效和无权限使用明确提示；无名单查看权限时提示正式报名后可查看。
- 创建页初始化失败可重试，昵称入口直达资料编辑；字段修改只清除相关错误。
- 发布成功立即跳转；跳转失败时保留已发布球局 ID 和查看入口，不会重复创建。提交期间无法清空草稿。
- 球局卡片标题与场馆支持两行，小屏信息允许换行；详情组织者操作采用两列布局并在窄屏改为单列；创建字段在窄屏改为上下布局。
- 固定操作栏改用主题表面色并增加安全区预留；减少动效模式取消卡片按压缩放。
