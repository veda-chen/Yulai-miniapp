# 羽来微信订阅消息接入说明

## 当前完成范围

- 消息页提供用户主动触发的微信订阅提醒入口。
- 模板 ID 未配置时不调用微信授权 API，并明确提示站内消息仍可用。
- 单次最多申请 3 个模板：球局变更、球局取消、候补递补。
- 用户授权结果以模板为单位记录为接受、拒绝或永久拒绝。
- 授权记录只允许通过云函数访问，集合权限为 `ADMINONLY`。
- 接收者 OpenID 使用独立密钥进行 AES-256-GCM 加密，数据库不保存明文。
- 用户注销时立即删除全部订阅授权和加密接收映射。
- 拒绝订阅不会影响创建、报名、候补、退出或站内消息。

## 公众平台配置步骤

1. 在微信公众平台确认小程序服务类目可以使用所需订阅消息模板。
2. 分别选择适合“球局变更”“球局取消”“候补递补”的一次性订阅模板。
3. 记录每个模板的正式模板 ID 和字段名称；不要使用其他小程序的模板 ID。
4. 将模板 ID 填入 `apps/miniprogram/config/subscription.ts` 对应项目。
5. 在开发环境体验版中由用户点击消息页的“设置”按钮，核对微信弹窗文案。
6. 保存接受、拒绝和永久拒绝三种结果的测试记录。
7. 根据正式模板字段实现发送数据映射，再启用发送任务。
8. 在生产环境使用独立的 `SUBSCRIPTION_OPENID_KEY`，不得复用开发密钥。

## 尚未启用的发送部分

当前不调用订阅消息发送接口。原因是正式模板 ID 和每个模板的数据字段尚未确定，提前编写发送内容会产生无法验证的字段映射。取得模板后，需要增加发送适配器，将 `notificationJobs` 中的业务事实映射为模板字段，并使用加密接收映射发送。发送失败应记录错误码和重试次数，不记录明文 OpenID。

## 验收口径

- 模板为空时点击设置只显示说明，不弹出微信订阅窗口。
- 模板有效时，授权操作只能由用户点击触发。
- 每次传入 1 至 3 个模板 ID。
- 服务端拒绝未知模板类型、无效模板 ID 和无效授权状态。
- 普通用户只能读取和修改自己的授权记录。
- 数据库与云函数日志不出现明文 OpenID 或加密密钥。
- 注销账号后不再保留订阅授权记录。
