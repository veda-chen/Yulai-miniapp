# 羽来微信订阅消息接入说明

## 已配置模板

- 预约申请处理通知（编号 528）：用于球局变更和取消，字段为 `thing6`、`time10`、`thing2`、`thing13`、`thing24`。
- 信息提交成功通知（编号 600）：用于候补递补成功，字段为 `thing1`、`time18`、`thing12`、`thing8`、`thing5`。
- 客户端按模板 ID 去重，因此共用的变更模板在一次授权请求中只出现一次。

## 当前实现

- 消息页仅在用户点击后调用微信订阅授权。
- 授权结果以模板为单位记录为接受、拒绝、永久拒绝或已消费。
- 授权记录只允许云函数访问，集合权限为 `ADMINONLY`。
- 接收 OpenID 使用独立密钥进行 AES-256-GCM 加密，数据库不保存明文。
- 球局变更、取消和候补递补会同时生成站内通知和微信订阅消息任务。
- 用户注销时删除订阅偏好和加密接收映射。
- 拒绝订阅不会影响创建、报名、候补、退出或站内消息。

## 发送机制

云函数每分钟处理待发送任务，将球局数据映射到公众平台的真实字段。发送时仅在内存中解密接收 OpenID；成功后一次授权标记为已消费，失败时记录错误码并最多尝试三次。任务与日志均不记录原始 OpenID。

开发、体验和正式环境分别使用以下跳转版本：

- `developer`
- `trial`
- `formal`

部署时通过 `WECHAT_MINIPROGRAM_STATE` 指定当前版本。生产环境必须使用独立的 `SUBSCRIPTION_OPENID_KEY`。

## 字段映射

球局变更和取消：

- `thing6`：球局名称
- `time10`：球局开始时间
- `thing2`：场馆名称
- `thing13`：已变更或已取消
- `thing24`：变更说明或取消原因

候补递补：

- `thing1`：球局名称
- `time18`：球局开始时间
- `thing12`：场馆名称
- `thing8`：候补递补成功
- `thing5`：进入羽来查看球局详情

## 验收清单

- 相同模板 ID 在一次授权请求中只出现一次。
- 服务端拒绝未知模板类型、非当前小程序模板 ID 和无效授权状态。
- 普通用户只能读取和修改自己的授权记录。
- 球局变更、取消和候补递补分别生成正确字段。
- 成功发送后授权状态变为已消费。
- 可重试错误最多尝试三次；明确无授权等错误不再重试。
- 数据库和云函数日志不出现原始 OpenID 或加密密钥。
- 体验版分别验证接受、拒绝和永久拒绝。
