## 数据录入对应关系

| 核验资料 | 场馆或场地字段 |
| --- | --- |
| 入口和步行路线 | `entranceGuide` |
| 开放时间及临时闭馆规则 | `openingHours` |
| 校内外人员进入要求 | `accessPolicy` |
| 预约渠道和线下费用说明 | `bookingInstructions` |
| 可公开联系电话 | `contactPhone` |
| 洗手间、更衣、淋浴、无障碍等 | `facilities` |
| 授权后的封面图和平面图 | `coverFileId`、`floorPlanFileId` |
| 核验日期和来源 | `verifiedAt`、`verificationSource` |
| 场地楼层、地面、灯光和位置 | Court 的 `floorName`、`surface`、`lighting`、`locationHint` |

未取得可靠内容时保持 `null` 或空数组，页面会明确显示“待核验”或“暂无资料”。
