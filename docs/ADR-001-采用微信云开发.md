# ADR 001 采用微信云开发

## 状态

已接受，2026年9月8日生效。本决定替代《羽来技术架构设计和开发排期 V0.1》中关于 NestJS、PostgreSQL、Docker 和独立 HTTPS API 的技术选型，产品范围和十二周里程碑保持不变。

## 背景

羽来是微信小程序，当前由小团队开发，组局是主流程，组队和计分是可选功能。项目需要长期运营，但 M1 更需要降低登录、部署和运维成本。用户决定使用微信云开发。

## 决定

1. 小程序使用原生 TypeScript 和 `wx.cloud`。
2. 后端使用一个名为 `api` 的 TypeScript 云函数作为模块化入口，内部按用户、场馆、球局、报名、分组和计分划分模块。
3. 云函数通过 `getWXContext` 获取可信的 OPENID，客户端不得提交 OPENID 作为身份依据。
4. 云数据库保存业务数据；客户端默认不能直接读写业务集合，所有权限和状态变化由云函数处理。
5. 云存储保存场馆图片和平面图。
6. 报名、退出和候补递补使用云数据库事务。比分采用版本字段和仅追加修订记录，防止静默覆盖。
7. 开发和生产使用不同云环境及不同密钥。

## 结果

M1 不再维护独立服务器、PostgreSQL、Prisma、Docker 或自签发登录令牌。开发速度和部署复杂度降低，但数据模型、索引、权限和事务必须显式维护，不能依赖客户端页面保证安全。

## 复核触发条件

只有云函数执行时间、数据库查询能力、成本或平台限制连续阻碍业务目标时，才评估云托管或独立后端。迁移前先通过监控和压测确认瓶颈。
